# Plugins

Plugins add updaters and aggregators or configure quant-ranger for a deployment.

| Type                                                           | Summary                                                        |
| -------------------------------------------------------------- | -------------------------------------------------------------- |
| [One-off updater](one-off-updaters.md)                         | A Python file for proofs of concept and non-recurring work     |
| [Installable updaters and aggregators](installable-plugins.md) | Add new updaters/aggregators (discovered through entry points) |
| [Site configuration](site-configuration.md)                    | Deployment-wide defaults and templates                         |
